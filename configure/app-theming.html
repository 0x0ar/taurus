App theming

Taurus can recolor other apps with the same palette as the shell, whether it comes from the wallpaper (Matugen) or from a preset. Open Settings → Theme → App theming. The page lists the apps that are currently themed. Add another one from Add app, or remove one with the delete button on its tile.

Add app only offers apps that are installed. Nothing is installed for you, and an app that is switched on but not installed is skipped.

On by default: Bash, Kitty, Cava, GTK and Qt. Everything else is opt-in.

How it works​

Every time the colors change, Taurus renders each enabled app's template with matugen into a separate theme file, such as ~/.config/kitty/themes/taurus.conf. It then adds a single include line to the app's own config so the app loads that file.

Your config files are never overwritten. The lines Taurus adds are wrapped in markers:

# >>> taurus theme >>>
include themes/taurus.conf
# <<< taurus theme <<<

If one of your existing lines would override the theme (for example another theme = line), it is commented out as # taurus-disabled: ....

When you switch an app off, Taurus removes its block, restores the lines it commented out, deletes the generated theme file and puts back any setting values it changed. A config file it had to create is removed again if nothing else was added to it.

When a config can't be edited safely, for example because it is a read-only file managed by Home Manager or its structure is unusual, nothing is changed. A warning button appears on the app's tile. Click it to see what went wrong and the exact line to add yourself, with buttons to copy it and to open the folder.

Apps are only reloaded when their colors actually changed. A broken template only affects its own app, never the shell or other apps.

Customizing a built-in app​

Press the edit button on an app's tile. Its files are copied to ${XDG_CONFIG_HOME:-~/.config}/taurus/matugen/apps/<app>/ and the folder opens. The folder button at the top of the page opens the parent folder.

  • The template files use matugen syntax, such as {{colors.primary.default.hex}}, {{colors.surface.default.hex_stripped}} or {{mode}}. They are rendered again on every color change.
  • app.json describes where the theme file goes and which line is added to the app's config. It usually doesn't need changes.
  • The reset button restores the built-in version. Your copy is kept in ~/.local/state/taurus/matugen/backup/.

Only built-in apps can be customized this way. Folders with other names are ignored.

Command line​

taurus info theme apps
taurus set theme app <id> [on|off|toggle]
