Installation

IMPORTANT

Migrating from v1: All previous configuration will be backed up and unused. Configuration of compositor settings such as monitors, keybinds, and autostart is now up to you, as the project migrated from being dotfiles to being a shell.

Taurus installs on Arch Linux and its derivatives (pacman, with systemd or OpenRC). Other distributions are not supported for now.

Use this installer:

curl -fsSL https://0x0ar.github.io/taurus/install.sh | bash

If this doesn't work, use:

bash -c "$(curl -fsSL https://raw.githubusercontent.com/0x0ar/taurus/main/install/install.sh)"
NOTE

To update, run the installer script again and choose Update.

In the installer's configuration list, Default browser lets you pick Firefox, Chromium, Brave, or Zen. The installer adds the matching package, sets it as the system default browser, and points the Mod+F compositor bind at it. Your choice is saved for later updates.

Arch Linux and derivatives​

Arch Linux and its derivatives (EndeavourOS, Manjaro, CachyOS, Garuda, Artix and others) are supported on systemd, OpenRC and other init systems. Umbriel is installed from the AUR package umbriel-git, so an AUR helper is required; the installer sets up yay if none is present.

Build from source on Arch​

Arch-based distributions can build Taurus as a native package from this repository instead of running the installer script. The package installs the shell system-wide and pulls in every runtime dependency the installer would. The parts of the installer that change your home directory, services, or login screen are not done by a package, so you run them yourself afterwards.

The repository contains two PKGBUILDs in packaging/aur, and they conflict with each other:

PackageBuilds
taurusThe latest tagged release
taurus-gitThe latest commit on main

Install the build tools:

sudo pacman -S --needed base-devel git

Then clone the repository and build the package:

git clone --depth 1 https://github.com/0x0ar/taurus.git
cd taurus/packaging/aur/taurus
makepkg -si

For the latest commit instead of the latest release, use cd taurus/packaging/aur/taurus-git. makepkg -si installs the remaining dependencies with pacman, builds the package, and installs it.

IMPORTANT

Do not run the installer script on a system where Taurus is installed this way. It would place a second copy in ~/.local/share/taurus and link it over the packaged one. Update by rebuilding the package, as described below, and use the steps that follow for anything the installer would otherwise do. If the in-app update notification offers to run the installer, ignore it.

Manual setup​

The packaged files live in /usr/share/taurus. These steps copy what you need into your home directory and are written to be pasted into a shell one after another, since later steps reuse variables from earlier ones.

share=/usr/share/taurus
cfg="${XDG_CONFIG_HOME:-$HOME/.config}"

1. Compositor config​

Install the compositors you want, for example sudo pacman -S hyprland. The package lists Hyprland, Niri, Sway, Mango, and Umbriel as optional dependencies. Then copy the matching config. Choose one row:

Compositorcompdir
Hyprlandhyprlandhypr
Niriniriniri
Swayswaysway
Mangomangomango
Umbrielumbrielumbriel
comp=hyprland
dir=hypr

if [ -d "$cfg/$dir" ]; then
    backup="$cfg/${dir}_backup/backup_$(date +%Y%m%d_%H%M%S)"
    mkdir -p "$backup"
    cp -a "$cfg/$dir/." "$backup/"
fi
mkdir -p "$cfg/$dir"
cp -r "$share/compositors/$comp/." "$cfg/$dir/"

Your existing config is backed up first. Files with the same name in the new config replace yours, so move any personal settings back from the backup afterwards.

2. Kitty, Cava, and Fastfetch configs​

for app in kitty cava fastfetch; do
    mkdir -p "$cfg/$app"
    cp -r "$share/config/$app/." "$cfg/$app/"
done

This replaces files with the same name. Skip any app whose config you want to keep.

3. Wallpapers​

pictures="$(xdg-user-dir PICTURES 2>/dev/null)"
if [ -z "$pictures" ] || [ "$pictures" = "$HOME" ]; then
    pictures="$HOME/Pictures"
fi
wallpapers="$pictures/Wallpapers"
repo="${XDG_CACHE_HOME:-$HOME/.cache}/taurus-wallpapers"

mkdir -p "$wallpapers"
git clone --depth 1 https://github.com/ilyamiro/shell-wallpapers.git "$repo"
find "$repo" -path "$repo/.git" -prune -o -type f \
    \( -iname '*.jpg' -o -iname '*.jpeg' -o -iname '*.png' -o -iname '*.gif' -o -iname '*.webp' \) \
    -exec cp -t "$wallpapers" {} +

This is the full wallpaper pack. To keep only a few, copy those files out of $repo instead of running the last command.

4. Taurus settings​

This merges the default settings with any settings you already have, keeps your values, and points the shell at your wallpaper folder:

settings="$cfg/taurus/settings.json"
mkdir -p "$cfg/taurus"
[ -s "$settings" ] || echo '{}' > "$settings"

jq -s --arg wp "$wallpapers" '(.[0] * .[1]) * {wallpaperDir: $wp}' \
    "$share/config/taurus/settings.json" "$settings" > "$settings.tmp" \
    && mv "$settings.tmp" "$settings"

bash "$share/src/scripts/location.sh" --refresh

The last command detects your location for the weather widget. Skip it if you prefer to set the location by hand.

5. Services​

On systemd, enable the audio stack, networking, and power profiles:

sudo systemctl --global enable pipewire wireplumber pipewire-pulse
systemctl --user enable --now pipewire wireplumber pipewire-pulse
sudo systemctl enable --now NetworkManager power-profiles-daemon

On OpenRC, dinit, runit, or s6, enable NetworkManager and power-profiles-daemon with your init system's tools, and make sure PipeWire and WirePlumber start with your session.

6. Qt icon theme​

for qt in qt6ct; do
    mkdir -p "$cfg/$qt"
    [ -f "$cfg/$qt/$qt.conf" ] || printf '[Appearance]\nicon_theme=Adwaita\n' > "$cfg/$qt/$qt.conf"
done

if [ -z "$QT_QPA_PLATFORMTHEME" ] && ! grep -rqs '^QT_QPA_PLATFORMTHEME=' "$cfg/environment.d"; then
    mkdir -p "$cfg/environment.d"
    printf 'QT_QPA_PLATFORMTHEME=qt6ct\n' > "$cfg/environment.d/taurus-qt.conf"
fi

If you already have a qt6ct.conf, set icon_theme=Adwaita under [Appearance] yourself. Log out and back in for the environment variable to apply.

7. SDDM login screen (optional)​

The theme files are already installed. Install SDDM and its Qt dependencies, then configure it:

sudo pacman -S --needed sddm qt6-declarative qt6-svg

[ -f /etc/sddm.conf ] && sudo mv /etc/sddm.conf "/etc/sddm.conf.backup.$(date +%Y%m%d_%H%M%S)"

sudo mkdir -p /etc/sddm.conf.d
sudo tee /etc/sddm.conf.d/10-material-you.conf > /dev/null <<'CONF'
[Theme]
Current=material-you
ThemeDir=/usr/share/sddm/themes

[General]
InputMethod=
CONF

/etc/sddm.conf overrides the files in /etc/sddm.conf.d, so it is moved aside. To run the greeter on Wayland, add these two lines under [General]:

DisplayServer=wayland
GreeterEnvironment=QT_WAYLAND_DISABLE_WINDOWDECORATION=1

If another display manager is enabled, disable it before enabling SDDM, for example sudo systemctl disable gdm. Then enable SDDM:

sudo systemctl enable sddm.service

8. First launch​

Show the welcome guide on the next start:

rm -f "${XDG_STATE_HOME:-$HOME/.local/state}/taurus/first_launch.done"

Log in to your compositor. The configs from step 1 start Taurus on login. If you kept your own compositor config, add taurusd start to its autostart.

Optional extras​

Set TAURUS_EXTRAS to a space-separated list before running the installer:

TAURUS_EXTRAS="tmux openrgb" bash install/install.sh
  • tmux: installs tmux and an Omarchy-style ~/.config/tmux/tmux.conf (an existing file is kept as tmux.conf.taurus-backup).
  • openrgb: installs OpenRGB, a rgb-off.service that turns all lighting off at boot. The RGB tab of the settings window (Mod+H) needs OpenRGB.

Updating and removing​

To update, pull the repository and build again. The new package replaces the installed one:

cd taurus
git pull
cd packaging/aur/taurus
makepkg -si

Removing the package leaves everything in your home directory alone:

sudo pacman -Rns taurus

Delete ~/.config/taurus, ~/.local/state/taurus, and ~/.cache/taurus yourself if you also want your settings gone.
